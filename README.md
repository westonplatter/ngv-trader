# media

Images for PRs and docs (screenshots, GIFs), kept off `main` so the codebase
stays free of binaries. This branch shares no history with `main`; never merge
it.

- One folder per feature under `screenshots/`.
- Link with `https://raw.githubusercontent.com/westonplatter/ngv-trader/media/<path>`.
- To skip this branch when cloning: `git clone --single-branch <repo-url>`.

See `docs/contributing/commits-and-prs.md` on `main`.
